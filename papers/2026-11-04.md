### 1. CAREFUL-Bench: Effect-Aware, Judge-Free Evaluation of Multi-Turn LLM Function Calling

- **arXiv ID**: [2611.02978](https://arxiv.org/abs/2611.02978v1)
- **Authors**: Alexander Kovalenko, Artem Redchych
- **Categories**: cs.AI, cs.SE
- **Published**: 2026-11-02
- **Relevance**: title:function calling, title:multi-turn, title:LLM, abstract:function calling, abstract:multi-turn, title:function call
- **Abstract**: The multi-turn checker of the Berkeley Function Calling Leaderboard (BFCL) evaluates final state correctness but ignores the effects of intermediate calls: extra calls are free, function documentation does not describe side effects, and the scripted user never responds to proposals. Consequently, models asking for confirmation before destructive actions are penalized; 260 of 734 reference turns in the base category perform destructive actions without confirmation. We make BFCL effect-aware without replacing it. We infer effect declarations for all 128 functions by executing them in BFCL simulators and comparing state changes, with destructive writes identified by three annotators. A judge-free replay scorer reproduces official results across all 800 reference trajectories while reporting unrequested destructive calls, duplicate writes, redundant reads, surplus steps, and their token costs.

### 3. SpecOPD: Branch-Parallel On-Policy Distillation for Speculative Decoding

- **arXiv ID**: [2611.02846](https://arxiv.org/abs/2611.02846v1)
- **Authors**: Tianyu Liu, Jun Zhang, Wenjie Huang, Yuhao Shen, Tianqi Xu, Xinyue Hao, Hongyaoxing Gu, Xuyang Liu
  *(and 7 more)*
- **Categories**: cs.AI
- **Published**: 2026-11-02
- **Relevance**: title:on-policy distillation, title:distillation, abstract:on-policy distillation, abstract:distillation, abstract:agent, title:on-policy
- **Abstract**: Speculative decoding (SD) accelerates large language model inference by reducing the sequential cost of token-by-token generation. Advanced SD methods reduce proposal cost with parallel drafters that predict entire blocks in one forward pass, but overall speedup still depends on acceptance length. On-policy distillation (OPD) can push well-trained drafters beyond acceptance-length plateaus, yet conventional pipelines collect supervision through sequential draft-and-verify rollouts. Our key insight is that on-policy supervision need not inherit these dependencies: a draft block can be supervised using only its reference prefix and draft-sampled history. We propose SpecOPD, a branch-parallel OPD framework that parallelizes draft sampling and target supervision across independent branches drawn from the evolving drafter policy at reference anchors.

### 4. Meet Students Where They Are: Student-Prefix Teacher Adaptation for On-Policy Distillation

- **arXiv ID**: [2611.03133](https://arxiv.org/abs/2611.03133v1)
- **Authors**: Xue Zhang, Songming Zhang, Yunlong Liang, Fandong Meng, Yufeng Chen, Jinan Xu
- **Categories**: cs.CL
- **Published**: 2026-11-02
- **Relevance**: title:on-policy distillation, title:distillation, abstract:on-policy distillation, abstract:distillation, title:on-policy
- **Abstract**: On-policy distillation (OPD) mitigates the student's exposure bias by optimizing on student-generated trajectories. However, student-generated prefixes may contain reasoning errors or follow patterns unfamiliar to the teacher, undermining the reliability of its token-level supervision. This degradation becomes more pronounced as prefixes grow longer. To address this teacher-side distribution mismatch, we propose Student-Prefix Teacher Adaptation (SPTA), which adapts the teacher to the states on which it is queried during distillation. Specifically, before OPD starts, we collect student rollout prefixes with random lengths and continually train the teacher to continue from the prefixes using reinforcement learning with verifiable rewards (RLVR).

- **Published**: 2026-11-02
- **Relevance**: title:on-policy distillation, title:distillation, abstract:on-policy distillation, abstract:distillation, title:on-policy
- **Abstract**: Reinforcement learning (RL) elevates joint audio-video generation, but optimizing heterogeneous, modality-specific audio and video rewards often introduces cross-modal interference. On-policy distillation (OPD) alleviates this issue by transferring the capabilities of specialized audio and video RL teachers into a single student model. ### 8. From Local Skills to Long-Horizon Web Tasks: Progressive Skill Exploration for LLM Web Agents

- **arXiv ID**: [2611.03116](https://arxiv.org/abs/2611.03116v1)
- **Authors**: Xueyang Feng, Xiaohe Bo, Xu Chen, Quanyu Dai, Feng Wen
- **Categories**: cs.AI
- **Published**: 2026-11-02
- **Relevance**: title:agent, title:LLM, abstract:on-policy distillation, abstract:distillation, abstract:agent
- **Abstract**: Large language models (LLMs) are driving autonomous agents toward real-world environments, with the Web emerging as one of the most representative interaction scenarios. However, training Web agents with naive exploration remains challenging: successful trajectories are rare, and the sparse terminal rewards make it difficult for agents to obtain useful feedback from failed trajectories. Inspired by skill acquisition theory, we propose Skill-Composed Progressive Exploration (SCOPE), a short-to-long learning framework for long-horizon Web agents that decomposes complex task exploration into a gradual expansion process from local skills to complete task-solving capability. Specifically, SCOPE iteratively explores around local skills: Skill Discovery extracts reusable local skills and failure experiences from historical rollouts; Skill Orchestration composes discovered skills into high-level skill chains; and Skill Expansion leverages failure experiences aligned with the current skill chain to guide the agent toward exploring new subskills. Through this process, SCOPE progressively constructs task-completing skill chains across rollouts and internalizes them into the policy parameters through agentic on-policy distillation.

- **Abstract**: OPSD provides dense supervision for agentic reinforcement learning through privileged information feedback. - **Abstract**: Reinforcement learning (RL) has improved the capabilities of large language models (LLMs) across a wide range of tasks. ### 18. Distilling Literary Sentiment from LLM Annotations into an Ordinal BERT Model

- **Authors**: Artem Suslov, Takehiro Hashimoto
- **Categories**: cs.CL
- **Published**: 2026-11-02
- **Relevance**: title:distilling, title:LLM
- **Abstract**: The scarcity of human-annotated literary corpora limits the development of domain-specific sentiment analysis models. This study investigates whether LLM-generated annotations can supervise smaller models for literary sentiment analysis. We fine-tune five BERT models using ordinal regression on 10,889 literary sentences annotated by Gemma 4 31B on a ten-point sentiment scale.
