- **Authors**: Haowen Hou, Gen Li, Ruilin Li, Yicheng Liu, Zhen Huang, Shuai Dong, Congcong Wang, Kaiwen Tuo

- **Published**: 2026-11-25
- **Relevance**: title:on-policy distillation, title:distillation, title:agent, abstract:on-policy distillation, abstract:distillation, abstract:agent
- **Abstract**: Fully online on-policy distillation (OPD) is costly for long-horizon agents because each update depends on fresh environment rollouts. Prefix replay offers an efficient alternative by sampling current-student responses from stored histories, reducing idle time for long-tail rollouts and allowing each collected trajectory to support multiple updates. However, our analysis of the complete prefix replay pipeline identifies two limitations in long-horizon settings. In trajectory collection, teacher-only trajectories miss student-induced histories, while broader history coverage can reduce teacher reliability. In trajectory reuse, fixed position-based schedules cannot identify critical decisions that may occur at any trajectory depth.

### 5. InstructTTS-OPD: On-Policy Distillation for Multi-Objective Instruction-Following TTS

- **arXiv ID**: [2611.33937](https://arxiv.org/abs/2611.33937v1)
- **Authors**: Haitao Li, Tian Tan, Yuguang Yang, Guanrou Yang, Wenhao Guan, Chenglin Li, Shan Yang, Xie Chen
- **Categories**: cs.LG, cs.AI, eess.AS
- **Published**: 2026-11-25
- **Relevance**: title:on-policy distillation, title:distillation, abstract:on-policy distillation, abstract:distillation, title:on-policy
- **Abstract**: Instruction-following text-to-speech (Instruct-TTS) renders a target transcript in the manner described by a free-form natural-language instruction, and a good rendition must succeed on three fronts at once: following the instruction, pronouncing the transcript correctly, and sounding natural. Reinforcement learning has become the standard way to post-train such generative models toward human preferences, and TTS systems increasingly adopt it. When the three objectives are optimized together under a single scalar reward, typically with group relative policy optimization (GRPO), training tends to be unstable: the objectives compete, and the shared update drifts toward whichever one is easiest to improve, producing a seesaw among them. We instead adapt on-policy distillation (OPD), which fuses several single-objective teachers by matching their velocity fields on the student's own rollouts. Realizing this for Instruct-TTS first calls for a sound reward on each axis, which we analyze carefully: a distilled Qwen-Omni proxy for the costly Gemini judge, dialect-free data for the WER reward, and DNSMOS in place of the language-biased UTMOS.

### 7. Failure Broadens, Success Sharpens: Continual Adaptation of Tool-Use Agents Across Diverse Tasks with Dual-Polarity Memory

- **arXiv ID**: [2611.33612](https://arxiv.org/abs/2611.33612v1)
- **Authors**: Tianmai M. Zhang, Hoda Shajari, Amr Hendy, Xiaohu Liu, Piyush Behre, Omar Zia Khan, Ankur Gupta
- **Categories**: cs.CL
- **Published**: 2026-11-25
- **Relevance**: title:tool-use, title:agent, abstract:agent
- **Abstract**: Large language model agents can self-improve over time by utilizing procedural memory derived from prior task trajectories, yet the distinct utilities of memories derived from local successes and failures remain underexplored. This work studies this question in a realistic setting with heterogeneous streams of multi-domain tool-use tasks and various environment constraints common in real-world scenarios. We develop \emph{Dual-Polarity Memory with Periodic Maintenance} (DualPM), a simple, retrieval-free memory workflow characterized by (1) customizable reflection and procedural memory generation from both local successes and failures within each trajectory, and (2) periodic memory consolidation over long task streams under a given memory capacity, preventing memory explosion. Online prequential evaluation with fine-grained metrics reveals that failure memory more strongly broadens coverage, success memory better streamlines execution, while combining both polarities effectively integrates both benefits. Further studies demonstrate that DualPM enables cross-domain memory generalization and continual memory adaptation, while external evaluation on EvoMemBench reveals the portability and effectiveness of DualPM as a general long-term procedural memory method.

### 8. Rethinking Knowledge Distillation for Diffusion Language Models

- **arXiv ID**: [2611.33670](https://arxiv.org/abs/2611.33670v1)
- **Authors**: Yuxuan Sun, Yuanjian Xu, Jianing Hao, Yu Li, Sowmen Das, Zhong Li, Sangwoong Yoon, Miguel R. D. Rodrigues
- **Categories**: cs.CL
- **Published**: 2026-11-25
- **Relevance**: title:distillation, title:knowledge distillation, abstract:on-policy distillation, abstract:distillation
- **Abstract**: Knowledge distillation has recently proven highly effective for improving autoregressive models, but its applicability to DLMs remains poorly understood. We present the first systematic study of KD for DLMs and uncover two non-intuitive failures of classical forward-KL (FKL) distillation: (i) student perplexity does not improve monotonically with more teacher-generated data, and (ii) on the same teacher-generated corpus, FKL distillation underperforms simply training the student with the original DLM denoising objective. To address them, we propose a unified, data-free distillation framework for masked DLMs. First, the framework runs an off-policy distillation phase that absorbs general knowledge from a static set of teacher-generated data. Then, the framework employs on-policy distillation which consists of three techniques: a trajectory loss along the student's own reverse process, confidence reweighting that down-weights tokens where the teacher is unsure, and a trust-region anchor that stabilizes the moving target.

- **Categories**: cs.LG
- **Published**: 2026-11-25
- **Relevance**: title:tool-use, abstract:tool use
- **Abstract**: Tool use learned during supervised fine-tuning (SFT) is not always retained during reinforcement learning (RL). We study how properties of SFT data may affect this retention by constructing Low, Medium, and High SFT datasets with approximately matched token budgets but different tool-call depths. ### 17. Can Its Own Misses Teach an MLLM to Find Small Brain Metastases?

- **arXiv ID**: [2611.33836](https://arxiv.org/abs/2611.33836v1)
- **Authors**: Yixuan Duan, Kexin Geng, Hanwen Xu, Wei Qiu
- **Categories**: cs.AI
- **Published**: 2026-11-25
- **Relevance**: title:LLM, abstract:agent
- **Abstract**: Multimodal large language models (MLLMs) are becoming general readers of medical images, yet they remain weak at locating small abnormalities. Brain metastases expose this gap: at 384 px a 0.1 mL lesion covers less than a quarter of one visual token, and at one false positive per scan frontier MLLMs find fewer than 30% of lesions of 0.1-1 mL. Fine-tuning on one dataset helps but transfers poorly, and improving it further is slow trial and error steered by a single score. We introduce LANTERN (Lesion-finding AgeNt Through Error-driven Recursive learNing), a framework in which an MLLM improves recursively from its own misses. LANTERN recasts model development as an error-driven loop: a failure census attributes every missed lesion to one of four causes, an LLM mentor revises one of four levels (evidence acquisition, visual representation, learning policy, decision aggregation) per round, and a rule frozen before the first round decides what is kept, without test data and with every tool call audited.

### 18. EVA: Evidence-seeking Visual Agent for Hallucination-Resistant Multimodal Reasoning

- **arXiv ID**: [2611.33706](https://arxiv.org/abs/2611.33706v1)
- **Authors**: Ting Lei, Yu Chen, Yang Liu
- **Categories**: cs.AI
- **Published**: 2026-11-25
- **Relevance**: title:agent, abstract:agent
- **Abstract**: Hallucinations in multimodal large language models (MLLMs) often arise from visual assumptions that go unchecked. Self-reflection, multi-agent debate, and counterfactual verification can reinforce erroneous conclusions when they rely on the same unverified visual assumptions. External visual tools can provide verifiable evidence, but models may select the wrong tools, supply incorrect parameters, or ignore or contradict the evidence they obtain.
