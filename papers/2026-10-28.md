### 1. EvoRouter: Cost-Efficient Multi-Agent Routing via Insight-Guided On-Policy Distillation

- **arXiv ID**: [2610.35690](https://arxiv.org/abs/2610.35690v1)
- **Authors**: Yitao Xiao, Xu Zhang, Ye Cheng, Shaoyong Guo, Yan Sun, Ziyue Zhu, Sitao Xie, Guo Tong
  *(and 1 more)*
- **Categories**: cs.AI, cs.MA
- **Published**: 2026-10-26
- **Relevance**: title:on-policy distillation, title:distillation, title:agent, abstract:on-policy distillation, abstract:distillation, abstract:agent
- **Abstract**: Serving web queries at scale with multi-agent systems requires jointly configuring large language models, collaboration modes, agent counts, interaction rounds, and skills. However, the resulting configuration space grows combinatorially, while sparse execution rewards provide limited fine-grained supervision for interdependent planning decisions. We propose EvoRouter, a self-evolving multi-agent routing framework driven by insight-guided on-policy distillation. A dedicated expert periodically synthesizes performance-cost feedback from configuration trajectories across tasks into reusable conditional routing insights about capability requirements, returns from resource scaling, and interactions among configuration choices. A privileged teacher combines these evolving insights with current execution feedback to provide dense token-level supervision for the router's own planning trajectories through on-policy distillation.

### 2. When Fine-Grained Credit Assignment Helps and Hurts: Multimodal Agentic Reinforcement Learning through Video Editing

- **arXiv ID**: [2610.35497](https://arxiv.org/abs/2610.35497v1)
- **Authors**: Lei Zhao, Zongheng Cao, Xinyu Hu
- **Categories**: cs.LG
- **Published**: 2026-10-26
- **Relevance**: title:agent, title:agentic, abstract:tool use, abstract:distillation, abstract:agent
- **Abstract**: Reinforcement learning (RL) has shown promise for training multimodal agents to reason and use tools. However, it remains unclear when fine-grained credit assignment improves learning and when it fails to improve task performance. Video editing provides a useful testbed for this question, combining multimodal perception, long-horizon planning, and tool use with delayed outcome feedback. We construct four movie-trailer editing task types---Content Selection, Narrative Sequencing, Rough Cut, and Fine Cut---that reflect real-world editing workflows and span different levels of task complexity and interaction horizon. Decaying process rewards provides the largest benefit on Fine Cut, with a 45.4% relative gain over outcome-only GRPO on tasks averaging more than 60 turns under outcome-only GRPO.

- **Abstract**: Recent work has explored optimizing LLM collaboration through Multi-Agent Reinforcement Learning (MARL), but many approaches still rely on predefined workflows, limiting efficiency and scalability. - **Abstract**: We present the Infinity Machine, a self-improving AI agent that we use for research on problems whose answers aprogram or data can check. ### 10. Learning When to Commit: Schedule Distillation for Fast Diffusion Language Models

- **arXiv ID**: [2610.35804](https://arxiv.org/abs/2610.35804v1)
- **Authors**: Aidar Myrzakhan, Zhiqiang Shen
- **Categories**: cs.CL, cs.AI, cs.LG
- **Published**: 2026-10-26
- **Relevance**: title:distillation, abstract:distillation
- **Abstract**: Diffusion large language models (dLLMs) can generate multiple tokens in parallel, but often require many decoding rounds to complete a response. Efficient generation depends not only on which tokens are easy to predict, but also on how committing to them helps predict the remaining positions. A highly predictable token may provide little useful context, while revealing a less predictable token can help several other positions become predictable sooner. We propose dSpark, a new schedule distillation-based framework for learning when to commit tokens for faster diffusion language generation. To achieve this, we construct unmasking schedules that prioritize tokens whose reveal makes other positions easier to predict, reducing uncertainty earlier in decoding.

- **Abstract**: Skills provide agents with reusable experience to guide future decisions without modifying the underlying model. ### 12. Adaptive Memory Index Evolution for Agents

- **arXiv ID**: [2610.34977](https://arxiv.org/abs/2610.34977v1)
- **Authors**: Yuntong Hu, Tongli Su, Yuanfu Sun, Shuo Ma, Qiaoyu Tan, Liang Zhao
- **Categories**: cs.LG
- **Published**: 2026-10-26
- **Relevance**: title:agent, abstract:agent
- **Abstract**: Long-horizon agents continually accumulate experience, yet retaining a memory does not guarantee access when it is needed. Existing systems can adapt both memory content and access; we isolate persistent access updates as a separately controlled adaptation layer. We formulate this target as Memory Index Evolution and instantiate it with Adaptive Memory Index Evolution (AMIE), a lightweight plug-in layer that evolves per-memory access state from deployment retrievals without modifying stored content or retraining the host memory system. AMIE distils a semantic teacher's keep/suppress judgments into a retrieval-conditioned policy and accumulates its selective actions into bounded state that reweights subsequent host retrievals. Surprisingly, even a zero-call policy that simply accumulates retrieval frequency can match or outperform semantic policies in several settings, revealing retrieval traffic itself as a strong signal for access adaptation, while learned selectivity improves robustness when frequently retrieved memories remain useful.

### 14. Linear Probes Transfer from Base to Distilled Language Models despite Rotation

- **Authors**: Marios Tsatsos
- **Categories**: cs.AI, cs.CL, cs.LG
- **Published**: 2026-10-26
- **Relevance**: abstract:distillation
- **Abstract**: Linear probes, classifiers that read a language model's internal activations, are widely used to detect harmful requests. They are cheap to train and run, and an auditor who has trained one would like to reuse it when the model is replaced by a successor rather than retrain it for every release. We test how well probes can be reused. For four base models (Qwen2.5-Math-7B, Llama-3.1-8B, Qwen2.5-14B, Qwen2.5-32B) we train a probe on the base model with the XSTest prompt set and apply it, unchanged, to two successors of that base: the DeepSeek-R1 distilled reasoning model and the developer's instruction-tuned chat model. We find that the successors rotate the direction separating unsafe from safe prompts by 17$^\circ$ to 35$^\circ$, yet on XSTest the transferred probe's AUC changes by only $-0.011$ to $+0.027$, and on an independent OR-Bench evaluation, never used for training, by $-0.015$ to $+0.053$.

### 15. ThinkBit: Search Codewords, Recalibrate Scales, Select by Reasoning

- **arXiv ID**: [2610.34886](https://arxiv.org/abs/2610.34886v1)
- **Authors**: Rhea Sanjay Sukthanker, Pashmina Cameron
- **Categories**: cs.AI, cs.CL
- **Published**: 2026-10-26
- **Relevance**: abstract:distillation
- **Abstract**: Reasoning language models generate thousands of tokens per answer, and generation speed is limited by memory bandwidth, so storing weights in two bits instead of bfloat16 can potentially make inference 8$\times$ cheaper. Two-bit methods are usually judged by perplexity and multiple-choice question-answering accuracy, both of which say little about whether a model can still reason through more difficult problems. We present ThinkBit, a strictly scalar two-bit framework built to preserve reasoning, in which every weight is an integer codeword times a bfloat16 scale shared by a group of weights. We first use a sensitivity metric to assign each layer a ternary, 2-bit, or 3-bit tier to allocate bitwidths optimally among layers. This is followed by a layerwise Gumbel-softmax-based scalar quantization algorithm that searches for optimal codewords block by block.

### 18. Did the Model Use That? Counterfactual Training Boosts Self-Attribution in Language Models

- **arXiv ID**: [2610.35295](https://arxiv.org/abs/2610.35295v1)
- **Authors**: Zikai Zhou, Jiacheng Sang, Yilin Xu, Yufei Jin, Monica S. Lam
- **Categories**: cs.CL, cs.AI
- **Published**: 2026-10-26
- **Abstract**: A fundamental challenge for explainable and accountable language models is revealing how external information influences their answers. This paper examines whether models are self-attributive: that is, whether they indicate when -- and only when -- their responses to questions are influenced by information provided alongside the question. Furthermore, we explore how self-attribution can be improved through counterfactual training, which explicitly teaches models to distinguish between answers that do and do not depend on supplied information. We found that most of the eleven frontier models rarely attribute influential information in their answers, and the rest attribute non-influential information. Training acknowledgment into reasoning does not fix this: the acknowledgment does not reach the final answer.
