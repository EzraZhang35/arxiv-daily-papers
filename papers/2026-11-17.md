### 1. Interactive Structured Environment Scaling for Large Language Model Agentic Reasoning

- **arXiv ID**: [2611.19871](https://arxiv.org/abs/2611.19871v1)
- **Authors**: Peng Yu, Luoyi Fu, Xinbing Wang, Ying Wen
- **Categories**: cs.AI, cs.LG
- **Published**: 2026-11-15
- **Relevance**: title:agent, title:agentic, title:large language model, abstract:tool use, abstract:agent, abstract:multi-turn
- **Abstract**: Reinforcement learning via environmental interaction is a cornerstone post-training paradigm for evolving large language models into autonomous agents capable of multi-turn tool use and exploration. Because the environment defines what the policy observes and how actions are verified, its structure directly bounds the capabilities an agent can acquire. Yet existing structured and retrieval environments rely on upstream pre-filtering---extracting a compact subgraph around the gold answer or retrieving fixed passages before the policy acts. We show that such pre-filtering introduces a fundamental measurement confound: because per-question subgraphs enclose ground-truth paths, they compress the candidate space by orders of magnitude and leak answer locations via local topology, allowing a question-blind degree heuristic to surface gold answers far above chance. To restore path selection, candidate pruning, and optimal stopping as genuine policy decisions, we propose RISE (Interactive Structured Environment), which transitions structured reinforcement learning from static subgraphs to full-scale interactive databases along two coupled axes.

### 2. Where Should LLM Agents Adapt at Test Time? In Context, in Weights, or Both

- **arXiv ID**: [2611.19700](https://arxiv.org/abs/2611.19700v1)
- **Authors**: Parsa Mirtaheri, Mohammadreza Armandpour, Keivan Alizadeh, Iman Mirzadeh, Parshin Shojaee, Aryo Lotfi, David Harrison, Mehrdad Farajtabar
- **Categories**: cs.LG, cs.AI, cs.CL
- **Published**: 2026-11-15
- **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:distillation, abstract:agent
- **Abstract**: LLM agents operating repeatedly in the same environment, such as a code repository, a database, or an application suite, encounter tasks that share latent structure. Experience can reveal this structure, allowing agents to reuse environment knowledge and learn from environmental feedback. Agents can adapt at test-time using this experience through two channels: retaining it in context and updating their weights. These channels are usually studied separately, leaving unclear what each contributes and when they complement each other. We compare in-context learning (ICL), reinforcement learning with verifiable rewards using GRPO, and self-distillation using SDPO, alone and in combination, using a shared online protocol and modular framework.

### 3. Towards Agentic Scientific Discovery in Distributed Systems

- **arXiv ID**: [2611.20031](https://arxiv.org/abs/2611.20031v1)
- **Authors**: Rashmita Soni, Abhirup Ghosh, Soumya Banerjee
- **Categories**: cs.AI
- **Published**: 2026-11-15
- **Relevance**: title:agent, title:agentic, abstract:agent
- **Abstract**: We investigate when adaptive tool selection helps identify a shared equation across clients with different input coverage. Query-ATLAS (query-conditioned Agentic Tool-based Learning for Aggregating Symbolic Equations) uses an LLM to guide symbolic search from client errors and previous proposals in a simulated distributed system. A four-architecture comparison reveals task-dependent opportunities: relative to fixed PySR-LLM, validation acceptances rise from 3/12 to 7/12 on CRK3 and from 11/12 to 12/12 on oscillator2, while MatSci3 favors the fixed workflow. Across 72 settings in a post-hoc six-task subset of eight development tasks, Query-ATLAS achieves 64 validation and 64 in-distribution passes, versus 62 and 59 for the fixed workflow; both pass 47/60 eligible out-of-distribution tests. The fixed workflow retains lower median errors and cost.

### 4. A Matrix with Steps: An Episodic and Procedural Memory Method for Tool-Using Agents and Robots

- **arXiv ID**: [2611.20230](https://arxiv.org/abs/2611.20230v1)
- **Authors**: Jürgen Paulhart, Peter Schüller
- **Categories**: cs.AI
- **Published**: 2026-11-15
- **Relevance**: title:agent, abstract:agent
- **Abstract**: Agents that call tools and robots that execute tasks are challenged by two shortcomings: they repeat what failed before, and they learn from runs that they only believe succeeded. We describe the construction of a memory that addresses both, built for a production agent platform. Every run is recorded as an episode, and only an outcome confirmed by an external check, a test, a tool result or a person counts; the agent's own claim never does. What is learned from episodes is kept in a memory with two parts: an associative matrix, written with the delta rule, which finds the procedure that applies to a situation; and a section of ordered, addressable step records that answers what comes after a given step, where a step is a goal of the agent, not a motion. Because the matrix sums its associations, it keeps no order and cannot return or delete a single one; it serves as the finder, and order, outcome counts and deletion live in the records.

### 6. Learning When to Continue and When to Stop: Termination-Aware OPSD

- **arXiv ID**: [2611.19925](https://arxiv.org/abs/2611.19925v1)
- **Authors**: Chaoqun He, Wannian Yi, Changyi Sun, Chaojun Xiao, Lijie Wen
- **Categories**: cs.LG, cs.AI, cs.CL
- **Published**: 2026-11-15
- **Relevance**: abstract:distillation
- **Abstract**: On-Policy Self-Distillation (OPSD) improves language model reasoning by distilling from a frozen teacher initialized identically to the student and conditioned on privileged information. However, we identify an underexplored termination mismatch in OPSD: the student fails to reliably learn when to continue and when to stop. This mismatch manifests in two opposing failure modes-premature termination, where reasoning stops before sufficient progress is made, and repetition-driven over-generation, where the model continues generating after reasoning has stalled. Our analysis shows that the teacher-student discrepancy on EOS grows during OPSD training, while length-capped trajectories are frequently dominated by unproductive repetition. To address this issue, we propose TA-OPSD (Termination-Aware On-Policy Self-Distillation), which augments the original OPSD objective with two targeted objectives.

### 7. Discovering Programmatic Policies from Reinforcement Learning-Based Traffic Signal Controllers

- **arXiv ID**: [2611.19951](https://arxiv.org/abs/2611.19951v1)
- **Authors**: Lindong Xie, Yang Zhang, Beiyu Song, Zeren Xing, Flora D. Salim, Edward Chung
- **Categories**: cs.ET, cs.LG
- **Published**: 2026-11-15
- **Abstract**: Traffic signal control (TSC) is critical for mitigating urban congestion. Deep reinforcement learning (DRL) has achieved strong performance by learning adaptive policies from traffic observations, but learned neural controllers are often opaque, structurally complex, and difficult to generalize across scenarios. We propose PPL-TSC, a programmatic policy learning framework that distills compact and human-readable TSC policies from DRL teachers. PPL-TSC formulates policy learning as an evolutionary search over phase utility functions (PUFs), which score candidate signal phases and select the highest-utility phase for execution. Each generation consists of four steps: policy generation, policy review, policy calibration, and policy evaluation.
