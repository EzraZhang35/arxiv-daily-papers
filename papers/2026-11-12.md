### 1. Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation

- **arXiv ID**: [2611.14009](https://arxiv.org/abs/2611.14009v1)
- **Authors**: Lirui Luo, Kelong Mao, Xinwei Yang, Rongqing Li, Luyu Chen, Kieran Wong, Yudong Guo, Xinrui Wang
  *(and 4 more)*
- **Categories**: cs.LG, cs.AI, cs.CL
- **Published**: 2026-11-10
- **Relevance**: title:on-policy distillation, title:distillation, title:agent, abstract:on-policy distillation, abstract:distillation, abstract:agent
- **Abstract**: Language-model agents increasingly tackle long-horizon tasks whose interaction histories exceed the model's active context. They must therefore decide what to write down and what to read back, and when to do either. Recent work has begun to use on-policy distillation (OPD) to make memory control part of the policy, relying on memory tools and compaction protocols that lie outside either model's pre-training. However, this weakens the distillation on both sides: the teacher cannot give useful guidance on an interface it has never used, and the student samples too few meaningful memory actions for that guidance to take effect. To study this problem, we introduce Coding Agent Memory Gym II (CAMG-II), a suite of long-horizon agentic-RL environments spanning Shop, Coding, AutoResearch, General, and Visual.

### 2. Bootstrapped On-Policy Distillation

- **arXiv ID**: [2611.13680](https://arxiv.org/abs/2611.13680v1)
- **Authors**: Yue Wu, Xueyu Zhou, Yangrong Hu, Jian Huang
- **Categories**: cs.LG, cs.AI
- **Published**: 2026-11-10
- **Relevance**: title:on-policy distillation, title:distillation, abstract:on-policy distillation, abstract:distillation, title:on-policy
- **Abstract**: On-policy distillation (OPD) improves language models by distilling teacher predictions on student-generated trajectories, while on-policy self-distillation (OPSD) removes the need for an external teacher by using a reference-conditioned copy of the model as the teacher. Despite its great early improvements, we find that OPSD does not remain consistently effective under continued training and can eventually suffer substantial performance degradation. We study this training behavior and link the degradation to a growing mismatch between the evolving reference-free student and the frozen privileged teacher. In the early stage of OPSD, the privileged teacher remains closely aligned with the student and provides useful guidance for improving the student's generation trajectories. However, as training progresses, the growing distributional mismatch between the privileged teacher and reference-free student can cause the teacher to provide misleading supervision, ultimately degrading student performance.

### 3. SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering

- **arXiv ID**: [2611.13410](https://arxiv.org/abs/2611.13410v1)
- **Authors**: Genming Cui, Xiangyu Li, Zixu Hao, Xin Ding, Yunxin Liu, Ting Cao
- **Categories**: cs.AI, cs.LG
- **Published**: 2026-11-10
- **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:distillation, abstract:agent
- **Abstract**: Low-bit quantization reduces the inference cost of LLM agents but can compromise task success. Examining failed rollouts, we find that quantized agents overlook task requirements or environmental conditions, producing environment transitions that diverge from successful full-precision references. Correcting these behavioral divergences remains difficult: offline data may miss the student's failure contexts, while its own rollouts may provide few correct responses in those contexts. We introduce SteerDistill, a quantization-aware distillation method in which a full-precision teacher guides the student to revise failed responses and iteratively refines its guidance using feedback from student execution. This closed-loop teacher steering produces locally verified behavioral corrections.

### 4. When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents

- **arXiv ID**: [2611.14326](https://arxiv.org/abs/2611.14326v1)
- **Authors**: Runxuan Tang, Haoyu Gao, Yuyan Ding, Junyi Yao, Zihao Zheng, Zecheng Sheng, Liwei Hou
- **Categories**: cs.AI, cs.LG
- **Published**: 2026-11-10
- **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:agent
- **Abstract**: LLM agents increasingly operate in long-horizon, verifier-rich environments, but current self-improvement mechanisms often write episode-derived lessons directly into memory, making local success an unreliable signal for reusable and safe knowledge. This paper addresses the core question of when an experience-derived behavioral update should be admitted into persistent agent state. We propose Falsification-Gated Self-Evolution (FGSE), a verifier-grounded framework that represents each candidate lesson as a structured hypothesis with an explicit precondition, behavior change, expected effect, and verifier. FGSE applies the hypothesis only in a temporary state, tests it on target-transfer, falsification, and archived-regression probes, and then commits, refines, or rejects it according to measured gain and risk. Across web, app, tool-use, and long-term memory benchmarks, FGSE achieves strong task performance, including 39.8 WebArena success rate, 78.8 AppWorld average completion, and 0.724/0.487 Pass$^1$ on $τ$-Retail/$τ$-Airline, while reducing falsification failures to 5.0%, regression damage to 1.3%, and harmful committed updates to 3.6%.

### 5. Controlled Knowledge Engineering for Taxonomy Induction with Tool-Grounded LLM Agents and Runtime-Adaptive Policies

- **arXiv ID**: [2611.13966](https://arxiv.org/abs/2611.13966v1)
- **Authors**: Jonas Limniatis, Bennet Schaarmann, Georg Reuber, Robert Stahlbock
- **Categories**: cs.IR, cs.AI
- **Published**: 2026-11-10
- **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:agent
- **Abstract**: Taxonomies are structured knowledge representations that support semantic search, recommendation, product catalog organization, and retrieval-augmented generation. Their automated construction from a fixed set of candidate entities requires more than plausible text generation: the resulting hierarchy must be complete, structurally valid, and semantically coherent. Large Language Models (LLMs) are promising for this task, but iterative free-form generation remains vulnerable to omitted or hallucinated entities, invalid hierarchical relations, and inconsistent organizational principles. We introduce TIGA (Taxonomy Induction with Tool-Grounded Agents), a knowledge-engineering architecture that formulates taxonomy induction as an iterative decision process over an explicit state and constrained action space. TIGA combines executable taxonomy-editing tools, an memory that records tool calls, rationales, and outcomes, and a runtime-adaptive organizational policy that the agent revises during inference.

### 6. Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents

- **arXiv ID**: [2611.14320](https://arxiv.org/abs/2611.14320v1)
- **Authors**: Yukyeong Lee, Yumin Choi, Jinheon Baek, Sung Ju Hwang
- **Categories**: cs.AI, cs.MA
- **Published**: 2026-11-10
- **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:agent
- **Abstract**: External memory enables LLM agents to improve from experience by distilling trajectories of past tasks into concise lessons for new tasks. However, memory can also lead to memory-induced degradation, where an agent fails on tasks it would solve without memory, often because it follows a lesson that is incorrect, or misapplies or misreads a valid one. This is because lessons are inferred from trajectories labeled only with task success or failure, yet are typically provided without the trajectories they came from, leaving the agent no way to check them. To address this, we introduce WikiTrace, an evidence-linked memory system designed to let agents check each lesson against its original trajectory. Specifically, motivated by the finding that a trajectory often still holds the evidence needed to catch an erroneous lesson, WikiTrace stores each lesson as a concise insight linked to a summary of why its trajectory succeeded or failed and to the raw trajectory itself.

### 7. ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows

- **arXiv ID**: [2611.14492](https://arxiv.org/abs/2611.14492v1)
- **Authors**: Kaiyuan Hou, Yang Ping Kuo, Indranil Bhattacharya, Rohith Nama, Arushi Gupta, Carlos D. Castillo, Prathap Ramachandra, Xiaofan Jiang
  *(and 1 more)*
- **Categories**: cs.AI, cs.LG, cs.MA
- **Published**: 2026-11-10
- **Relevance**: title:distilling, title:agent, abstract:agent
- **Abstract**: Business process automation runs the same Standard Operating Procedure (SOP) again and again on new inputs. Large Language Model (LLM) agents can follow an SOP written in natural language, but they call an LLM to choose every step of every run, which adds latency and cost at scale. We present ReTrace, which turns an SOP and a few logged agent runs into a reusable workflow in which code, not an LLM, selects the next step. The agent's reasoning, the explanation it writes with each tool call, often states why it took an action; the tool calls alone do not. ReTrace extracts the condition behind each step, merges these conditions across runs into a compact rule document, and generates an executable workflow from it.

### 9. Beyond Passive Imitation: On-Policy Mid-Training Distillation for Language Models

- **arXiv ID**: [2611.13855](https://arxiv.org/abs/2611.13855v1)
- **Authors**: Ruize Zheng, Xuyang Liu, Siyu Ren, Xiaobing Tu, Yinggui Wang, Jinkui Ren, Xiantao Zhang, Linfeng Zhang
- **Categories**: cs.CL, cs.LG
- **Published**: 2026-11-10
- **Relevance**: title:distillation, abstract:distillation, title:on-policy
- **Abstract**: Continual pre-training (CPT) adapts large language models (LLMs) to specialized domains, yet its standard next-token prediction (NTP) objective treats every corpus token as a fixed target, regardless of its utility to the current model. In a controlled study on the same 1B-token mathematical corpus, we observe sharply different outcomes across base models: NTP improves Llama-3.2-3B's performance on mathematical benchmarks but substantially degrades Qwen3-1.7B-Base's performance, indicating that, under a fixed training recipe, the same training sequences can have model-dependent effects. To address this problem, we introduce On-Policy Mid-Training Distillation (OPMD), which reformulates mid-training from offline text imitation into active, query-driven knowledge acquisition. At selected anchor positions, OPMD samples trajectories from the evolving student policy and applies dense token-level reverse-KL rewards from a frozen teacher, training the model on states it actually visits rather than only on ground-truth prefixes. This on-policy objective reduces the training-generation mismatch of teacher-forced NTP.

### 10. Program-Aided Patchable Skill Evolution

- **arXiv ID**: [2611.14019](https://arxiv.org/abs/2611.14019v1)
- **Authors**: Jiahao Wang, Yuqi Xiong, Qing Yang, Zhipeng Xu, Zhenghao Liu, Zulong Chen, Yubin Bao
- **Categories**: cs.CL, cs.AI
- **Published**: 2026-11-10
- **Relevance**: abstract:agent
- **Abstract**: Agent skills have emerged as an effective means of enabling LLM agents to solve complex, interactive tasks by encoding reusable knowledge without modifying model parameters. Recent approaches further improve skill adaptation by distilling reusable experience from agent execution trajectories and evolving skills based on downstream task feedback. However, existing methods primarily represent skills as natural language documents, intertwining procedural logic with descriptive knowledge and making skills difficult to maintain and evolve. To address this limitation, we propose PASE (Program-Aided Patchable Skill Evolution), a program-aided framework that iteratively evolves skills by associating them with executable programs. Unlike prior approaches that encode trajectory-derived experience primarily in natural language, PASE separates reusable procedural logic into editable programs, enabling targeted updates to executable components while reducing the need to repeatedly revise natural language skills.

### 11. OpticalRAG: Pixel-Space Compression for Token-Efficient Retrieval-Augmented Generation

- **arXiv ID**: [2611.13675](https://arxiv.org/abs/2611.13675v1)
- **Authors**: Senhao Liu, Yuheng Zhang, Chunyu Wei, Yueguo Chen, Xinran Zhang
- **Categories**: cs.CL
- **Published**: 2026-11-10
- **Relevance**: abstract:distillation
- **Abstract**: Retrieval-augmented generation (RAG) is bottlenecked by the token budget of large language models: feeding long documents into the context window is expensive, while aggressive textual compression discards fine-grained information that is irreversibly lost in a one-dimensional token sequence. We argue that this bottleneck is not fundamental to information density but to the choice of compression \emph{modality}. Modern visual encoders can pack the contents of a rendered text page into roughly a hundred visual tokens with little semantic loss, opening a new compression-fidelity tradeoff that purely textual methods cannot reach. We present \textbf{OpticalRAG}, a framework that renders documents as page images, encodes them with a frozen vision encoder, and distills the retrieved visual tokens into as few as $16$ injected tokens before passing them to the LLM. Two ingredients make this work without expensive cross-modal training: (i) \emph{Encoder-Bridged Retrieval}, which projects text-query states into the visual feature space of the frozen encoder, through a projection shared with the compressor, to retrieve visual tokens from a text query, with no contrastive training; and (ii) \emph{Query-Driven Distillation}, a lightweight cross-attention compressor that condenses the retrieved visual tokens into a small set of query-conditioned prefix tokens.

### 12. Darmok: Championship Cryptic Crossword Solving via Constraint Tightening and Resilient Orchestration

- **arXiv ID**: [2611.13557](https://arxiv.org/abs/2611.13557v1)
- **Authors**: Siddhartha Chatterjee
- **Categories**: cs.AI, cs.CL, cs.DC
- **Published**: 2026-11-10
- **Abstract**: We present Darmok, the first automated system to reach superhuman performance on British cryptic crosswords. Unlike American-style crosswords, cryptic clues disguise an unmarked definition and compositional wordplay beneath a misleading surface reading, sparse grids leave nearly half of each word's letters unchecked, and tournament rules rank a grid with even a single wrong or blank square behind all error-free solutions regardless of speed. Competing alongside an elite human field at the 55th Times Crossword Championship in London, Darmok solved all seven championship puzzles error-free and finished faster than every human competitor in every round. It solved the Final puzzle in 6m 52s, a full 3m 13s ahead of the human champion. Today's frontier AI models can on average solve a whole puzzle in a single try with comparable accuracy and speed.
