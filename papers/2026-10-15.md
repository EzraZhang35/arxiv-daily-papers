### 1. Knowledge Graphs as Files: An Agent Harness Where Tool Creation and Tool Use Co-Evolve

- **arXiv ID**: [2610.18616](https://arxiv.org/abs/2610.18616v1)
- **Authors**: Yuyang Bai, Yu Wang, Yu Zhang
- **Categories**: cs.CL, cs.AI, cs.IR
- **Published**: 2026-10-13
- **Relevance**: title:tool use, title:tool creation, title:agent, abstract:tool use, abstract:agent, abstract:multi-turn
- **Abstract**: Searching text-rich knowledge graphs requires following relations while examining textual evidence. Predefined graph interfaces constrain what evidence agents can access, even when they write code to combine tool calls or process retrieved subgraphs. We propose direct knowledge graph interaction (DKGI), a harness in which language model agents create graph access tools directly over complete node and edge files. The agent writes Python code to follow relations, combine node sets, and select textual evidence, interleaving execution with shell search and file inspection. This lets agents process large node sets in bulk while returning selected text for the model to assess.

- **Abstract**: Large language model (LLM) agents have shown strong capabilities in interactive problem solving, tool use, and long-horizon task execution. However, they may also acquire sensitive or private knowledge during training and expose it during deployment. Retraining a model from scratch to remove such knowledge is prohibitively costly, making machine unlearning a more practical approach. - **Relevance**: title:agent, title:LLM agent, title:LLM, abstract:agent
- **Abstract**: Large language model (LLM) agents are becoming an integral part of the software development lifecycle, and the capabilities granted to them allow an agent to act with the user's authority on any resource it can access. The reach that gives an agent its utility is equally available to an attacker who can steer it. ### 6. Teacher-Guided Tool Learning for Small Language Models via Bidirectional KL Constraints

- **arXiv ID**: [2610.18459](https://arxiv.org/abs/2610.18459v1)
- **Authors**: Haoxuan Gao, Qin-Wen Luo, Xiang Chen, Yu Tian, Zequn Sun, Xiaofeng Cao, Jiangchao Yao, Sheng-Jun Huang
- **Categories**: cs.LG, cs.CL
- **Published**: 2026-10-13
- **Relevance**: title:tool learning, abstract:tool use, abstract:distillation
- **Abstract**: External tools can extend the capabilities of small language models (SLMs), enabling their deployment in resource constrained environments. However, their limited capabilities make it difficult for SLMs to discover effective tool use behaviors through reinforcement learning alone, while direct teacher supervision suffers from teacher student behavioral distribution mismatch and may propagate erroneous preferences. To address these challenges, we propose Selective Teacher guided Policy Optimization (SeTPO), which coordinates student exploration with selective teacher guidance and persistent demonstration supervision. Specifically, SeTPO incorporates reverse KL derived token level teacher feedback into policy advantages on low reward trajectories, while auxiliary forward KL supervision preserves teacher demonstrated behaviors throughout training. Under an idealized bidirectional KL objective, we theoretically establish that the optimal policy achieves expected reward no lower than the teacher's while retaining a guaranteed fraction of the teacher's probability mass.

### 9. Does self-distillation improve reasoning?

- **arXiv ID**: [2610.18613](https://arxiv.org/abs/2610.18613v1)
- **Authors**: Jason Ken Adhinarta, Raina Wu, Ashutosh Sharma, Avinash Balakrishnan, Rameswar Panda, Polina Golland, Yoon Kim, Zhang-Wei Hong
- **Categories**: cs.LG, cs.AI, cs.CL
- **Published**: 2026-10-13
- **Relevance**: title:distillation, abstract:tool use, abstract:distillation
- **Abstract**: Self-distillation is an emerging approach that trains a model to imitate its own predictions when conditioned on privileged information, such as correct answers or environmental feedback. Recent methods have reported better sample efficiency and generalization than reinforcement learning (RL), but it remains unclear whether these gains extend beyond in-distribution evaluations and whether they stem from privileged distillation. In this paper, we revisit two representative methods, Self-Distillation Policy Optimization (SDPO) and On-Policy Self-Distillation (OPSD), across code, science, tool use, and math reasoning tasks. We find that their reported gains do not consistently generalize to unseen problems and are largely explained by overfitting or transferring existing reasoning behavior, rather than effectively using privileged information. Moreover, self-distillation gradients show weak alignment with policy gradients that directly optimize expected reward, questioning whether they provide an effective direction for policy improvement.

### 10. Reading Right, Acting Wrong: Diagnosing Decision Failures of System One Models in Agent Loops

- **arXiv ID**: [2610.18579](https://arxiv.org/abs/2610.18579v1)
- **Authors**: Yubo Li, Ramayya Krishnan, Rema Padman
- **Categories**: cs.AI
- **Published**: 2026-10-13
- **Relevance**: title:agent, abstract:tool use, abstract:agent
- **Abstract**: System One models choose an agent's next action by scoring a supplied set of options in a single pass. This makes them fast and cheap, but when they choose wrongly there is nothing to inspect: did the model misread what the agent has seen, or read it correctly and still act wrongly? We answer behaviorally. On a frozen benchmark of agent decision states from simulated environments, customer-service policies, tool use, web navigation and coding, we pair every next-action question with factual probes about the same state, each answered independently. Across seventeen fast systems and a reasoning model, the answer is consistent: most wrong actions follow correct reading, and the more accurate a system, the more of its errors take this form.

- **Authors**: Giovanni Pio Delvecchio, Stefano Fantazzini, Giacomo Frisoni, Gianluca Moro, Lorenzo Bacchiani, Mario Bravetti, Thomas Troels Hildebrandt
- **Categories**: cs.SE, cs.AI
- **Published**: 2026-10-13
- **Relevance**: title:LLM
- **Abstract**: Large language models increasingly generate Solidity smart contracts that, once deployed, can never be patched, making a single latent fault permanent and exploitable. Yet current evaluations mostly ask only whether generated code compiles. We introduce SolBehave, a benchmark for evaluating the correctness of model-generated contracts at scale, moving beyond ad hoc unit tests. Across 250 real, reproducible Ethereum contracts, we apply three complementary tests of behavioural fidelity: differential fuzzing, historical-transaction replay, and, as our core contribution, synthetic-transaction replay guided by a Dynamic Condition Response (DCR) graph that enumerates the space of legitimate function-call sequences. Differential fuzzing compares each generated function with the original on automatically generated inputs; historical replay compares the whole contract on the transactions it actually received on-chain; DCR-guided replay compares it on sequences of calls that follow its intended usage, including orderings that never occurred on-chain.

- **Categories**: cs.AI, cs.CL
- **Published**: 2026-10-13
- **Relevance**: abstract:agent
- **Abstract**: Tool-call judges evaluate argument values proposed by LLM agents. We find that they accept a correct value less often when their input holds no reference for it, that is, no text that says what the value should be. ### 17. Coupled Harness--Model Evolution for Scientific Equation Discovery

- **arXiv ID**: [2610.17740](https://arxiv.org/abs/2610.17740v1)
- **Authors**: Pengze Li, Jiaquan Zhang, Encheng Su, Yunbo Long, Zihang Zeng, Xinping Liu, Han Zhang, Junchi Yu
  *(and 3 more)*
- **Categories**: cs.AI
- **Published**: 2026-10-13
- **Relevance**: abstract:agent
- **Abstract**: Large language models (LLMs) are increasingly used to discover scientific equations from experimental data. Such a discovery system has two parts that must work together: a library of executable computational tools and the model's tool-use policy. The tools supply the solving capability, from diagnosing structure in the data to fitting candidate equations; the policy plans and orchestrates their use. Yet existing systems adapt only one part, keeping either the toolset or the model fixed, which leaves the corresponding failures uncorrectable. We develop a coupled evolution framework that improves both parts from the same verifiable fit-error signal.
